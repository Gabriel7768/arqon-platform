# ARQON Platform — ADR-001

## Final Architecture Review — Internationalization Platform (Architecture Freeze)

Before writing any implementation code, stop.

Do not create files.

Do not modify existing code.

Do not install packages.

Do not migrate components.

Do not generate translations.

Your only objective is to produce the definitive architecture specification for the ARQON Internationalization Platform.

This document will become the official architecture reference for the entire project.

After this document is approved, the architecture must be considered frozen.

Future implementation must follow this specification.

---

# Context

During Phase 1 you completed a complete audit of the frontend.

That audit identified:

* all hardcoded strings
* localization risks
* duplicated logic
* formatting limitations
* scalability issues
* migration strategy

Now perform the final architecture review before implementation begins.

This is an architecture exercise.

Not an implementation exercise.

---

# Important Change

Replace every previous proposal that places the localization module inside:

lib/i18n

The final architecture must instead use:

packages/i18n

This package must become a platform service.

It must not depend on:

* React
* Revenue Engine
* API
* Database
* Authentication
* UI components

React integration must exist only as an adapter layer.

---

# Review Every Architectural Decision

Review and validate every proposed module.

Challenge your own design.

Remove unnecessary complexity.

Split modules that have multiple responsibilities.

Merge modules that overlap.

The objective is maximum cohesion and minimum coupling.
